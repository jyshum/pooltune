Functions and scheduled jobs

Choose specific functions and jobs Pooltune may consider. Choosing a target allows the background agent to check it under your selected repair permissions and limits.

Function repairs require a supported function, measured disk spill, a safe limit on calls receiving extra memory and available capacity. Scheduling repairs require repeated job interference, comparable completed database work, on-time jobs and scheduler acknowledgement. Application-wide request and error rates remain unobserved.

Check project activity for repair progress and outcomes. Enrollment alone does not mean a repair has been verified.

Database functions

Only functions owned by the connected database login are listed. Functions with elevated execution permissions and extension-managed functions are excluded. For eligible functions, Pooltune limits how many calls receive extra memory. Other calls keep their original memory settings. Unsupported functions remain unchanged.
