Set up the Pooltune agent

Pooltune installs a dedicated database login to read workload statistics and discover queries from ordinary traffic. Choose which repairs the agent may consider.

Supabase setup access

Use one Supabase Management API token limited to this project with Database Write and Logs Read (Analytics Read). Pooltune uses it for setup, then keeps it encrypted on Railway for monitoring. The stored token still holds its Database Write permission; ongoing monitoring only reads data. Disconnecting removes the stored token.

Required when you select repairs. Use this project's existing postgres database password. Pooltune encrypts it for its background Go worker on Railway and removes its stored copy when you disconnect. PostgreSQL gives this login owner access. Pooltune checks your selected repairs before each action.

Investigate queries that repeatedly exceed this average duration in milliseconds. The default is 1000 ms. A repair still needs evidence of its cause and benefit.

Paste the certificate from your project’s database connection settings so Pooltune can verify the database’s identity over an encrypted connection.
