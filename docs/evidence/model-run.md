# Real model candidate evidence: October 24, 2026

A real Claude Haiku 5.5 call ran through the owned gateway HTTP handler, durable
accounting, bounded local agent loop and real policy compiler. Inputs were
explicitly synthetic workload metrics and approved local boundaries. This did not
activate traffic, test a live canary or validate provider compatibility.

The first attempt made four paid steps and did not produce a validated candidate.
Only the failure result was retained; the exact local rejection cause is unknown.
After adding sanitized diagnostics, the second attempt made seven steps and
produced a candidate that passed the compiler. Compiler rules were not relaxed.
The model then finished. A validated candidate is not evidence of beneficial policy.

Total ledger charge for both attempts: 5,854 micro-dollars ($0.005854), across 11
settled calls. No uncertain reservations remained. Accounting rounds each call
up to a micro-dollar and is a local estimate from usage/pricing, not an invoice.
The total development cap is $5 in one persistent ledger outside the repository.
No keys or installation tokens appear in these artifacts.

customer payload, 45-second call timeout. Verified standard rates for prompts
