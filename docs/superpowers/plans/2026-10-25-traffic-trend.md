# Measured traffic trend

User approved real transactions/sec plus a grey-to-cyan pixel trend on both private dashboards, matching Claude's design. Execute inline, preserve all existing dirty work, no cloud benchmark or website change.

Design: read PgBouncer SHOW STATS total_xact_count for the exact database in both local and gateway-owned poolers. Use cumulative counters rather than scheduler releases, which count protocol batches and can differ from SQL transactions. Send counter as decimal string, timestamp and opaque process epoch. Missing readings are null. Throughput is counter delta / elapsed source seconds. Reset on epoch changes, decreasing counter, stale/gapped/backward observations. Telemetry never controls admission. Keep 60 seconds of browser history. Pixel columns reflect measurements, grey normally and cyan above 1.5x prior recent mean after five readings. No invented idle animation. Counts include pooled internal work and rolled-back transactions, not HTTP requests or successful-only work.
